# UCI 配置全模块指南

> **验证说明**：本文基于在设备上（SSH `root@192.168.0.1`）的只读检查，全文仅执行 `uci show` / `uci get`，**未对设备执行写操作**。访问方式见 `AGENTS.md`「设备访问方式」。
>
> **约定**：每个模块一节，先述作用与关键条目，再述用途（多为只读观察；凡涉及写操作或数据面控制均标注风险，并指向对应主题文档）。
>
> **隐私约束**：个人/设备/卡片标识符（IMEI、IMSI、ICCID、MSISDN、序列号、完整 MAC、小区级标识等）一律省略或占位，**不写完整号码**；安全凭据（账号密码密文、salt、token、appvalue、enckey 等）一律不转录。

## 一、设备标识与系统（`zwrt_common_info` / `zwrt_product` / `system` / `fstab`）

**作用**：设备身份、软硬件版本、系统级配置、只读分区的挂载表。

```sh
uci show zwrt_common_info   # manufacturer, model_name(MU5250), hardware_version(MU5250_HW1.0)…
uci show zwrt_product       # 产品线、build_date
uci show system             # hostname, timezone, ntp
uci show fstab              # 16 个只读目标分区挂载表
```

**关键条目与可读信息**
- 厂商 `ZTE`、型号 `MU5250`、别名 `U60 Pro`、硬件版本 `MU5250_HW1.0`、平台 `X75`、固件构建日期 `2025-05-27`。
- `system.ntp.enabled=0`（时间同步由 `zwrt_zte_sntp` 的 NITZ 提供）。
- `fstab` 列出 `/data`、`/ai_app`、`/ai_data`、`/ztebat`、`/overlay`、`/etc_ro/manufacture` 等（`enabled=0`，实际挂载由 ZTE 机制完成）。

**用途**：识别固件版本/硬件批次用于比对差包；读取挂载点布局以判断哪些目录可 overlay 写（见 `docs/partitions.md`）。

## 二、网络与路由（`network` / `zwrt_router`）

**作用**：LAN/WAN/链路本地接口、rmnet 拨号、路由与多 WAN。

```sh
uci show network
uci show zwrt_router.network; uci show zwrt_router.dhcp; uci show zwrt_router.tmp_router
```

**关键条目**
- LAN 桥 `br-lan`：`192.168.0.1/24`，成员 `rndis0 ecm0 wlan0-3 eth0`。
- 直连口链路本地：`rndis 169.254.20.1`、`ecm .21.1`、`eth .22.1`、`eth_nic2 .23.1`、`eth_usb .24.1`、`wlan0-3 .30-.33`；`mhi_swip 169.250.25.26/30`（对应 `swip` zone）。
- WAN 拨号：`zte_wan`/`zte_wan6` `proto='rmnet'`、`profile=1`；`zwrt_router.network`：`opms_wan_mode='PPP'`、`ppp_dial_type='rmnet'`、`lte_cid_mask='1000'`、`rmnet_interface_keep=1`。
- WAN 槽位：4 个（`zte_wan[|_2|_3|_4]`）已定义，仅槽 1 启用。
- IPv6：`zte_wan6` 下发 LAN，`dhcpv6_mode='stateless'`、`ipv6_is_clear_ip=1`。
- 运行时状态：`zwrt_router.tmp_router.*`（`current_wan_status`、`wan_ipaddr` 等；检查当时为 `disconnected`）。

**用途**：只读观察链路本地直连（RNDIS/ECM）入口与 rmnet 拨号行为；配合 [ipc-protocol.md](ipc-protocol.md) 理解拨号状态。改静态 IP 或桥成员属写操作，须先行备份。

## 三、防火墙与 NAT（`firewall` / `zwrt_router.firewall` / `qcmap_firewall`）

**作用**：安全边界、NAT、端口映射、DMZ、QCMAP 侧防火墙状态。

```sh
uci show firewall; uci show zwrt_router.firewall; uci show qcmap_firewall
```

**关键条目**
- 标准 zone：`lan`(ACCEPT) / `wan`(`masq=1`、`mtu_fix=1`) / `swip`(`mhi_swip`) / `phantap`(DROP) / `wireguard`(`wg0/wg1`)。
- ZTE 网管 zone：`portmapping`/`portforward`/`dmz`/`natloopback`（均 `enabled=0`）。
- `zwrt_router.firewall`：`nat_enable=1`、`remote_web_access_enable=0`、`wan_ping_enable=0`、`portforward_enable=0`。
- 自定义脚本：`/etc/firewall.user`、`/sbin/firewall_init.sh`。

**用途**：只读核对哪些远程端口开放（当前远程 web / WAN ping 均关）；理解 LAN→WAN 经 NAT + mtu_fix 的转发链。任何放行或端口映射修改属写操作。

## 四、WiFi（`wireless` / `hostapd` / `wpa_supplicant` / `qcacfg80211` / `ezlbd`/`repacd`/`ezmesh`）

**作用**：射频、BSS、安全、回程/组网、负载均衡。

```sh
uci show wireless; uci show hostapd; uci show wpa_supplicant; uci show qcacfg80211
```

**关键条目**
- 芯片 `wcn7851`（`wireless.readonly.chipset`），`qcacld32` 驱动、`phy_map radio2-wifi0(2G)/radio5-wifi1(5G)`。
- feature `zte_mbb`：`wifi_onoff=1`、`wifi_onoff_by_user=1`、`wifi6_switch=1`、`mlo=0`、`mesh_onoff=0`（机制见 `docs/wifi.md`）。
- 主 AP `ssid='XXXX'`、`sae-mixed`（2.4G/5G 均开）；`guest_*` 与 `backhaul_*` 均 `disabled=1`。
- `wireless.readonly`：SSID 前缀/中缀(MAC 后 6 位)/后缀、密码长度 10、`wifi_key_encryption_type='private'`。
- 组网 daemon：`repacd`（回程/RE 平移检测）、`ezmesh`（EasyMesh/Multi-AP、IEEE1905）、`ezlbd`（LBD 负载均衡/Steering）、`wsplcd`（WPS/克隆）、`mesh_app`（数据元素上报）。

**用途**：只读读取 SSID/加密/频段/发射功率限制；对照 `docs/wifi.md` 理解 `wifi_onoff` 联动；`wsplcd.DebugLevel`、`wpa_supplicant.log.log_level=debug`、`wlan_services.cfg.enable_debug` 是排障可看的调试开关。改 SSID/密码/频段属写操作。

## 八、数据面 QCMAP（`qcmap_wlan` / `qcmap_wlan_current` / `qcmap_gsb` / `qcmap_ezmesh` / `qcmap_current_lan_config`）

**作用**：高通数据面的 WLAN/多网桥/组网配置，`*_current` 为运行时快照。

**关键条目**
- `qcmap_wlan.@wlanconfig[0]`：`mode=2`、`ifname=wlan`；`@mldwlanconfig`：`mode=1`（MLO，当前 `mlo=0` 未启用）。
- `@primaryap`：`band=2、apifname=wlan0、staifname=wlan1`；`@guestap`：`band=5、apifname=wlan1、staifname=wlan2`。
- `qcmap_gsb` / `qcmap_ezmesh`：同频/组网桥接参数；`qcmap_current_lan_config`：运行时 LAN 快照。

**用途**：对照 `*_current` 与 `qcmap_wlan` 看运行时与配置差异（绕开 QCMAP 缓存问题的排查入口）。这些由 `qcmap*` daemon 维护，手工改易被回写覆盖。

```sh
uci show qcmap_wlan; uci show qcmap_wlan_current; uci show qcmap_gsb; uci show qcmap_ezmesh; uci show qcmap_current_lan_config
```
